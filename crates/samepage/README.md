# samepage

**Name reserved — no API yet.** This `0.0.0` placeholder exists to hold the name
while the crate is built. The first real release will replace it.

SamePage is a shared surface where a person and an agent work on the same page.
The agent authors the UI, the person marks it, every mark carries an unforgeable
byline, and the surface describes itself back in relations — "sits right of",
"top edges aligned" — rather than coordinates.
