# DejaVuSansMono.ttf

Vendored from the DejaVu Fonts project (as shipped with matplotlib's `mpl-data`).
Used at renderer init to rasterize an ASCII glyph atlas for on-canvas text labels.

The DejaVu fonts are based on the Bitstream Vera Fonts and the Arev Fonts. Both
are distributed under permissive, redistributable licenses (free to use, copy,
modify, and redistribute, including embedding/bundling). See the upstream
DejaVu license: https://dejavu-fonts.github.io/License.html

Bitstream Vera and Tavmjong Bah (Arev) copyright notices are preserved per that
license. This file is bundled only as a glyph source for atlas generation.
